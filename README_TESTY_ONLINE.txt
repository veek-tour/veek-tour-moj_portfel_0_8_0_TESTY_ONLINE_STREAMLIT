MOJ PORTFEL 0.8.0 — TESTY ONLINE
=============================

1. Rozpakuj ZIP.
2. Prześlij ZAWARTOŚĆ folderu na GitHub (app.py i requirements.txt mają być w katalogu głównym repozytorium).
3. Uruchom/odśwież projekt w Streamlit Community Cloud, Main file path: app.py.
4. Testuj tylko na FIKCYJNYCH danych.

Nie publikuj prywatnej bazy SQLite ani swoich transakcji.
Wspólne wdrożenie online bez logowania może udostępniać dane innym, a baza może zniknąć po restarcie.
Wersja Windows 0.7.0 pozostaje bez zmian.

Szczegóły i lista ograniczeń: README.md.
Przypadki testowe: SCENARIUSZE_TESTOWE_080.md.
